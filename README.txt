CATÁLOGO LISTO PARA VISUAL STUDIO Y GITHUB PAGES

Todos los archivos de esta entrega están en la raíz.
No coloque estos archivos dentro de otra carpeta del repositorio.

PARA VERLO EN VISUAL STUDIO CODE

1. Descomprima el ZIP completo.
2. Conserve todos los archivos juntos en la misma carpeta.
3. Abra index.html. El catálogo incluye sus 3,737 propiedades y puede cargarlas
   aunque todavía no haya publicado el sitio.

PARA PUBLICAR EN GITHUB PAGES

1. Suba TODOS los archivos directamente a la raíz de su repositorio.
2. Confirme que index.html se vea junto a app.js, styles.css,
   properties-data.js y las imágenes.
3. En GitHub abra Settings > Pages.
4. Seleccione Deploy from a branch, rama main y carpeta /(root).
5. Guarde y espere a que GitHub muestre el enlace publicado.
